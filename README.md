# BioInformatics_Trained_Systems
B.I.T.S is a machine learning project made by  <a href="https://github.com/Adog-bits">@Adog-bits</a> and <a href="https://github.com/Gamefox229">@Gamefox229</a> to classify the likelihood of specific disease development based off of genome sequences.

**<ins>Checklist of Features to Add</ins>**

- Specific Disease for Benchmark Testing
- ML Model for Prediction
